# 0129 — Gio orders the records by drag & drop; the shop follows

`2026-11-22` · accepted (Gio: "vorrei in qualche modo poter ordinare i dischi via admin per decidere l'ordine in cui compaiono sul sito", "anche i draft vorrei poterli ordinare", "un semplice drag & drop, con la stessa logica degli altri drag order che usiamo nel admin"; published draft → "In cima a Live") · Figma: BACKEND → Listings → new component set `listings table row` (2413:1734, type head | row, boolean `handle`) in every desktop frame; COMPONENTS → `admin` → `listing row` gets boolean `handle` (on; off in Orders) · migration 0029

**Context.** The shop listed records newest published first and the admin newest created first: two orders, neither chosen by Gio.
**Decision.** One global order for every listing, `listings.sort_order` (numeric, lower = first). Every admin tab (Live, Drafts, Sold) and every shop list (`/sale/`, catalog, genres, search) shows it filtered, so a sold copy keeps its place. In Listings a row is dragged (pointer, whole row) or moved with ↑ ↓ on its drag handle (keyboard, announced), with the admin's one drag logic: `useDragOrder`, extracted from FileList (photos, samples) without changing it. A move puts the row halfway between its new visible neighbours (`admin_move_listing`); nothing else is renumbered, unless the gap is too small (then all are renumbered once). No ordering while searching (hidden rows sit between results) or in Archived. New listings go on top; a draft that is published goes on top again (trigger `listings_on_top`). A move of a public copy rebuilds the shop (~2 min); a draft does not. The home shelves This week and Recent stay newest published first: they are about what is new.
**Rule.** A list Gio orders by hand uses `useDragOrder` + `DragHandle` (pointer drag on the row, ↑ ↓ on the handle, polite live region); one ordering column per kind of thing, filtered views never get their own order.
**Where.** `supabase/migrations/20261122000000_listing_order.sql`, `packages/ui` (`useDragOrder`, `DragHandle`, FileList, ListingRow `handle`), `apps/admin/admin.js` (Listings `OrderedRows`, `moveRow`), `apps/admin/admin.css` (`.admin-sortable`), `apps/storefront/data/products.js` (`byListingOrder`), `apps/storefront/pages/home.js` (shelves by date).
