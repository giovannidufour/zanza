# 0179 — PLP pagination: records per page from admin Settings, page numbers with a gap, fluid on desktop

`2026-11-24` · accepted (Gio: "una classica paginazione con successiva, precedente, la pagina in cui sei, il poter cliccare su altre pagine, poter andare alla fine … un limite di prodotti visibili per pagina a 20"; "su desktop vorrei che la paginazione fosse fluid come la griglia"; "Ok, vai") · Figma: page `pagination` → `pagination` (2536:3462, device × position) + `_pagination gap` (2536:2749) + note; page `PLP` → `PLP - desktop / paginated`, `PLP - mobile / paginated`; BACKEND `Settings` → `number setting` + `Settings - desktop · records per page`

**Context.** PLPs listed every record on one page. Gio wants a limit set in the admin (20 to start) and a classic pagination.
**Decision.**
- Every PLP (For sale, For trade, search, wantlist, collections, catalog) shows `records per page` records a page: `shop_settings.records_per_page` (migration 0039, 1 … 100, default 20), set in admin → Settings → Records per page; saving rebuilds the shop.
- The page is `?page=N` on the same URL, handled in the browser. Every card stays in the HTML: filters, sort, "sold out at the end" and search work on all records, search engines see them all, canonical unchanged. Changing a filter or the sort goes back to page 1. A page link is a plain link: the soft navigation loads it (history entry, back to the top, the player keeps playing).
- Which numbers show: `packages/pagination/pagination.js` (one file for the build and the browser): always first and last, the current page and its neighbours (desktop ± 1, mobile none), a gap "…" for 2+ pages, a fixed number of slots (desktop 7, mobile 5).
- Look: secondary Buttons; the current page is `state="active"` (0045, link + `aria-current="page"`). Previous / Next only when there is a page to go to: hidden, never disabled (disabled = sold out, struck label). Desktop fluid: the bar fills the list column, pages and gaps share the width, Previous / Next hug their label. Mobile: 38 × 38 squares, arrows without label (aria-label "Previous page" / "Next page"). The gap is `aria-hidden`. `<nav aria-label="Pages">`, each number "Page N".
- One page of records = no pagination.
**Rule.** A long list pages with `packages/ui` Pagination + `packages/pagination`, never its own numbering; the page lives in `?page=`, any other change of the list resets it to 1; "you are here" is `state="active"`, never `disabled`.
**Where.** `packages/pagination/pagination.js`; `packages/ui/components.js` + `.css` + `.d.ts` (`Pagination`); `apps/storefront/pages/plp.js` (`PlpPagination`, `data-per-page`, template), `scripts/site.js` (initFilters → `paginate`, `renderPagination`), `build.js` (`site.perPage`, `/js/pagination.js`, `--per-page=` for local checks), `data/products.js`; `apps/admin/admin.js` (Settings); `supabase/migrations/20261124200000_records_per_page.sql`.
