# 0065 — Reserved: the Add button reads "(Reserved) Notify me", and the bag line looks like a sold one

`2026-11-12` · accepted (Gio, Figma example) · Figma: page `buttons` → `button` instance 2220:31582 (`prefix` "(reserved)", label "Notify me", trailing `icon/icon-envelope`, hierarchy secondary) · page `Bag` → `bag item` status=reserved 2226:10616 / 2226:10643

**Context.** 0059 made the Add button of a reserved copy read "Reserved", with a clock as the leading icon. Pressing it opened the dialog with Notify me. The label named the state but not what pressing it does, and the clock usually means "history" (design/open.md, 0059 open point 2).
**Decision.** A reserved copy's Add buttons (card, PDP, player) read "(Reserved) Notify me". `Button` gets a `prefix` (Figma `prefix`: same text style, gap 4, before the label). "(Reserved)" is the prefix, "Notify me" is the label, the trailing icon is `icon-envelope`, there is no leading icon, and the hierarchy is secondary. The button is still active and still opens the "Reserved" dialog (explanation and email). The accessible name is "Reserved. Notify me if it is back". On mobile the button reads only "Reserved" with the envelope (Gio, same day); the accessible name stays the same. The clock icon is no longer used by the shop.
**Bag (Gio, same day).** A reserved line in the bag is drawn exactly like a sold one (0064): the name is struck through and "RESERVED" sits beside the struck price, with no notice on top. The note above Checkout says it in full sentences, so a partial checkout is explicit (Gio, same day): "1 record is sold out and won't be in this order." / "1 record is reserved and won't be in this order. It may be back within 30 minutes." (plurals: "N records are…", "They may…"; the 30-minute line is left out when every held line is held by hand). The Checkout label stays "Checkout". This bends 0064's rule ("struck through = unavailable for good") and 0059's "a hold is not struck", but only for the bag. In the bag, struck through means *not in this order*, and that is true for a held copy too. Cards and the PDP keep the active "(Reserved) Notify me" button.
**Rule.** A button for a state that blocks the usual action says the state as a prefix in brackets and the action it offers as its label. It is never just the state. In the bag, anything not in the order is struck through and named beside its price.
**Where.** `packages/ui/components.js` (`Button` `prefix`, `EnvelopeIcon`), `components.d.ts`; `apps/storefront/build.js` (`zz-icon-envelope` template); `apps/storefront/scripts/site.js` (`syncAddButton`, `setPrefix`, `setTrailingIcon`, `syncBagLine`, `renderBag`); `BagItem` + `components.css` (reserved = sold styling).
