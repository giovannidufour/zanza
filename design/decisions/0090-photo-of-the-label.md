# 0090 — Memo: a photo of the label finds the record

`2026-11-15` · accepted · Figma: BACKEND → `Memo` (page 2296:9962): `memo photo` (state default | reading | read | not read), `memo add` boolean `photo` (on); frames "Memo - mobile · photo reading" and "· photo read"

**Context.** Gio jots records down on the phone (0087) and asked to just photograph the record and let the system find the Discogs release. Constraint from Gio: **free**, no paid API. Reggae 7"s often have no sleeve and no barcode, but the centre label prints artist, title, label and catalogue number.
**Decision.** Under Record, a secondary full-width button **Photo of the label** opens the back camera (`<input type=file accept=image/* capture=environment>`; a file picker on desktop). The phone shrinks the photo (longest side 1280 px, JPEG 0.85) and sends it to the admin-only Edge Function `read-label`, which asks a free vision model on **Cloudflare Workers AI** (Workers Free: 10,000 neurons a day; default `@cf/meta/llama-4-scout-17b-16e-instruct`, about 60 neurons a photo, so well over a hundred photos a day) for `{ artist, title, label, catno, barcode }`. The photo is never stored. The words read go into Record (Gio can fix them), and `discogs-lookup { fields }` searches Discogs: barcode, then catalogue number (with artist or label), then artist + title; up to 5 releases, shown in Record's usual list. Gio picks the pressing, or keeps the text. A status line under the button says what happened: "Reading the label…", "Read from the photo: …", or why not (unreadable, daily quota used up). The button then reads "Another photo".
**Rule.** Reading a photo only fills an input the user can still correct; the human picks the pressing. No paid AI in this project without Gio's ok: free tiers only, the key server side. A busy button keeps its normal look with `aria-busy` (disabled = strikethrough = unavailable in this DS).
**Where.** `apps/admin/admin.js` (PhotoField, shrinkPhoto, RecordField `found`), `apps/admin/admin.css`, `supabase/functions/read-label`, `supabase/functions/discogs-lookup` (`{ fields }`). Secrets: `CF_ACCOUNT_ID`, `CF_AI_TOKEN` (Workers AI Read only), optional `CF_AI_MODEL`.
