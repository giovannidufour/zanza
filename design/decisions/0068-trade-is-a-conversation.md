# 0068 — Trade: "not for sale, convince me"; the site starts a conversation, it does not run the deal

`2026-11-12` · accepted (Gio, thread "Plan record trades"; code built for testing the same evening) · Figma: page `Trade` (2229:7044): Trade PDP desktop/mobile, Trade offer desktop/mobile + sent, How trading works, About; components section

**Context.** For Trade lists records Gio does not want to sell. Trades are user ↔ Gio (Q2), one-shot, low volume. Gio's worry is trust in both directions. He does not want real-identity systems, and he does not want the site to impose a shipping rule ("you ship first"): the deal is found by talking, as in the Facebook trade groups.
**Decision.** A trade listing has no price ("Trade only") and one action, *Make an offer*, which opens `/products/<slug>/offer/`. The offer page asks for the records offered (1–5, each with Gio's grades), an optional pitch, and an **introduction**: a few words about the trader plus their Discogs and/or Instagram (at least one), where to talk (Discogs, Instagram, email, or we meet in person) and an email. Sending emails the offer to Gio (Supabase function `trade-offer`, Reply-To = the trader); nothing is stored and no account is needed. The listing's admin description is shown as Gio's note "Why it's not for sale". Gio's own trust is borrowed: his Discogs card (site.json → owner.discogs), his links on /about/. The listing goes *Reserved* only when Gio accepts an offer, *Traded* when it is done (admin, existing statuses). Gio's wantlist is never shown.
**Rule.** The site never promises how a trade is executed (who ships, when): it says that nothing is agreed until both say yes, and hands over to a person. Trust comes from people's existing profiles (Discogs, Instagram), not from data the shop collects.
**Where.** `apps/storefront/pages/trade.js` (TradeActions, Offer, HowTrading, About), `trade.css`, `pages/pdp.js`, `pages/shell.js` (trade cards link to the offer page, menu), `scripts/site.js` (initOffer; no Add to bag for trade in the player), `build.js` (/trade/, offer pages, /how-trading-works/, /about/), `site.json` → owner, trade; `packages/ui` (`TradeNote`, `DiscogsCard`, `TradeStep`, `GigRow`, Input `text-area`, ProductCard `addHref`); `supabase/functions/trade-offer`.

**Amended 2026-11-12 (Gio).** The site never talks about gigs: no gig list on the offer page or on /about/, no `GigRow` component. The in-person channel reads "Or we meet in person".
