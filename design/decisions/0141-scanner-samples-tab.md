# 0141 — Scanner Samples tab: Zoom session dragged onto draft clip slots, exported WAV + MP3 320 with tags and label cover; one drafts column for both tabs

`2026-11-23` · proposed · Figma: BACKEND → `Scanner`: section `samples · components` (`waveform` size small | large, `session clip` state default | playing | assigned | dragging, `clip slot` state filled | target | empty, `clip preview` state default | trimmed, `media status` kind images | clips × state some | none, `draft row` state default | hover | selected, `scanner tabs` mode scans | samples, `session head`, `export panel`); icons `icon/icon-image`, `icon/icon-waveform` (page icons); screens "Scanner v3 - samples, assigning / samples, no session yet / scans, same drafts column"; frame "notes · v3 samples tab, shared drafts column"

**Context.** Gio records the clips from his mixer onto a Zoom H4's SD card: Rec/Stop per side, records changed in between, while doing something else, with no Mac by the mixer. The Zoom often loses its clock, so the files have meaningless names and dates; renaming them by listening is the slow part. He rejected recording into the Mac and matching by draft order. He asked (2026-11-23) for a second tab in the Scanner app where the session's files are dragged into the draft's slots and renamed by the app, exported to chosen local folders as WAV (he may DJ with them) and MP3 320 with ID3 tags and the label of that side as cover and normalize to 0 dB (then parked, see Export); trimming silence only as an optional action; an in-app player. He feared that renaming on the SD card loses a wrongly dragged file. Then: the left column is the same for scans and samples, it lists every draft (search filters it) and each row shows small icons for images and samples already there.
**Decision.**
- **One drafts column for both tabs.** The full draft list, newest first; the search field filters it (no separate results). A row shows `media status`: image icon + scanned/slots, waveform icon + clips/slots (grey = none). Clicking a row opens it in place: Images (image slots of 0138) and Clips (one `clip slot` per Discogs position, names from `scan-targets`). `scanner tabs` (Scans / Samples) switch only the center and right columns. `draft row` replaces 0138's `draft result` + `draft head`.
- **Session.** The Zoom folder (or files) is dropped on the center or picked with Import…, and **copied** to a local session folder with the original names. The SD card is never written. Each `session clip` keeps its original name; assigning it to a slot only maps it (`STE-014 → 48213_b1_…`), visible on both sides, reversible (x, drop elsewhere, Cmd+Z). A clip fills one slot at most.
- **Preview.** `clip preview` plays the selected clip (Space, seek on the waveform). Trim silence is per clip and optional, start only (first sound above −45 dBFS, 50 ms kept), shaded cut, Undo trim; no fades (0110).
- **Export.** Per open draft, for each assigned clip: `<name>.wav` (source rate, 24-bit if the source is, else 16) and `<name>.mp3` (LAME, 320 kbps CBR, 44.1 kHz) into the two remembered folders; re-export overwrites. Volume: exported as recorded, no normalization (parked by Gio 2026-11-23: peak normalize is fooled by vinyl clicks, and a limiter would change the sound on a club system; he DJs from WAV and MP3). Tags in both files (ID3v2.4; WAV in an `id3 ` chunk): title and artist of the line, album = record title, label, year (not a decade), genre, track = A1/B1, comment = SKU; cover = the side's label scan from the Labels folder (role 1 for A, 2 for B), square JPEG 1000 px; none if not scanned yet. No automatic upload: the MP3 320 goes into the admin by hand and becomes 128 kbps there (0108).
**Rule.** A clip's name comes only from the slot it is dropped on (names computed by the backend, 0136/0138); the app never renames or deletes files on the source card. Any count shown on a draft row reads what exists (files on disk, assignments), never a guess.
**Backend.** `scan-targets { id }` also returns `clips [{ role, label, name, artist, title }]` and `tags { album, label, cat_no, year, genres }`. Read only, no migration. Redeploy the function.
**Where.** Figma (design); `supabase/functions/scan-targets/index.ts`; the Mac Scanner app (`apps/scanner`, branch of PR #202) builds the tab.
