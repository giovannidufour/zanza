# 0034 — Attributes: one admin page for artists, labels, subgenres and tags

`2026-11-10` · accepted (Gio) · Figma: BACKEND → Attributes (`2123:2053`, notes `2123:5507`)

**Context.** Artists, labels, subgenres and tags are entities (0006, 0007, 0011), created while typing a listing. Gio wants to list, edit, add and delete them by hand, and to clean up duplicates ("GREGORY ISAACS" vs "Gregory Isaacs") and combined legacy names ("DELLA GRANT & COLOUR RED").
**Decision.** One page with tabs Artists · Labels · Subgenres · Tags (count in the tab `suffix`, 0029), the same grammar as Listings: search, "New …", bulk bar always rendered (Merge with 2+, Delete), a table whose first column selects. Each entity has its own page with the Create layout: Name, Also written as (alias chips; artists and labels), Discogs ID, Slug, Records, and **Replace with**: one pick = merge (name and aliases become aliases of the target), several = split (artists, subgenres, tags; a release has one label). An entity on records is never deleted directly: Delete is disabled with the reason next to it (aria-describedby); the bulk Delete removes the free ones and lists the skipped ones. Every merge, split and delete is confirmed in a Dialog; the list's Merge asks which one to keep (Dialog `choices`, pre-selected: the one with a Discogs ID, then the most records). Printed credits never change. Database: migration 0012 (`admin_attributes`, `admin_entity`, `admin_save_entity`, `admin_replace_entity`, `admin_merge_entities`, `admin_delete_entities`), one transaction each.
**Rule.** Records of an entity = listings whose release uses it, archived included. Removing an entity that is on records always goes through Replace with. A count next to a heading in the admin follows Figma ("Records 2" as one text); a count next to a component label uses its suffix (0029).
**Where.** `apps/admin/admin.js` (`Attributes`, `AttributeForm`, routes `#attributes/<kind>[/<id>|/new]`), `apps/admin/admin.css` (toolbar, record links, `.admin-page--attribute`), `supabase/migrations/20261110100000_attributes.sql`.
