# 0140 — Memo: select memos and act on them in bulk (Create drafts, Remove)

`2026-11-22` · accepted · Figma: BACKEND → `Memo`: `memo item` boolean `select` (default ON; mobile = checkbox beside text + actions), `memo status` boolean `select all`, frames "Memo - desktop · selection", "Memo - mobile · selection"; BACKEND → `admin`: new component `bulk actions` (desktop bar, TEXT `selection count`)

**Context.** Gio adds many records to Memo and wants to turn several into drafts at once ("bulk actions in the Memo list, to create drafts for example"). Listings already has the grammar for it (0025, 0089).
**Decision.** Same grammar as Listings. Each `MemoItem` has a checkbox (`select` slot); the count line has **Select all** (checked / indeterminate). Desktop: the `bulk actions` bar is always rendered between the count line and the list ("N selected"; with a selection: **Create drafts**, **Remove**). Mobile: the same bar after the list, sticky at the bottom of the viewport while something is selected (`bulk bar`). Both actions ask first in a Dialog naming up to three memos. **Create drafts** runs the single-row Create draft (0135) one memo at a time ("Creating draft 2 of 5…"; Discogs releases are fetched, free text = line 1); created memos leave the list; failed ones stay selected and the status line says why; all fine = toast "N drafts created". **Remove** deletes the selected memos in one call, toast with Undo (0049). Per-row actions stay.
**Rule.** A list with more than one row-level action gets the Listings bulk grammar (checkbox per row, Select all, bulk bar always rendered on desktop / sticky on mobile, confirm Dialog); a bulk action reuses the single-row code path, never a second copy.
**Where.** `apps/admin/admin.js` (Memo: draftFromMemo, bulkCreate, bulkRemove), `apps/admin/admin.css` (`.admin-memo__count`), `packages/ui` (`MemoItem` `select`).
