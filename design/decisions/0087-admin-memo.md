# 0087 — Admin Memo: a quick list of records to sell later

`2026-11-15` · accepted · Figma: BACKEND → `Memo` (page 2296:9962): `memo item` (device mobile | desktop), `memo add`, `memo status`, `admin page title`; frames mobile (list, Discogs results, release chosen, empty) and desktop

**Context.** Gio finds records he could sell while listening at home or away, and wants to jot them down on the phone, in the admin, before he forgets. Free text must always work; picking the exact Discogs release is optional. Gio named the section "Memo" (not "To sell").
**Decision.** New admin page `#memo` (top bar button "Memo"). One form: **Record** = the offer form's release picker (`which record`, 0069) in the backend theme: free text, or 3+ letters search Discogs and a pasted release link resolves; **Note** optional; **Add to list** (primary, fill). The list below (newest first) is `MemoItem` rows: title, Discogs meta + "On Discogs ↗" when a release was picked, note, and two secondary small buttons. **Create listing** opens `#new/memo/<id>`: the listing form with Discogs match filled and fetched (free text only: the empty form, the memo shown in the status line); the first save takes the memo off the list. **Remove** deletes at once with an Undo toast (0049). No edit: remove and add again. Data: table `public.memos` (migration 0019, admin only); only the release id, its "Artist – Title" and meta line are kept from Discogs. Search goes through the admin-only Edge Function `discogs-lookup` (`{ query }`), the token stays server side; the shop's `discogs-search` keeps its origin allowlist.
**Rule.** A list on the admin is mobile first: rows stacked (`<ul>`, text then actions), not a table. Reuse the release picker for any "which record" input. A shortcut from one admin page to another passes data through the route (`#new/memo/<id>`), never through browser storage.
**Where.** `apps/admin/admin.js` (Memo, RecordField, FromMemoLoader, ListingForm `fromMemo`), `apps/admin/admin.css`, `packages/ui` (`MemoItem`), `supabase/migrations/20261115000000_memos.sql`, `supabase/functions/discogs-lookup`.
