# 0110 — Clip a sample: Length Full / Clip, cut in the admin from the start

`2026-11-17` · accepted · Figma: none yet. `sample row` (2095:20507) has no Length / Duration fields (design/open.md)

**Context.** Gio uploaded whole tracks (~4 min, ~3.5 MB at 128) as samples; the brief says 30–60 s clips, lighter and closer to a preview (Q3, rights). He wants to choose per sample whether to cut. Proposal discussed in the thread: Length + Duration + play to check. Gio: "no fade-in, Duration ok, Start not needed, the play is great".
**Decision.** Samples overview, under each sample's title: **Length** select: `Full` (default) / `Clip 30s` / `Clip 60s` / `Clip 90s` (Gio, same day: ready values, the free Duration (s) field is gone; a clip as long as the file or longer is disabled). Choosing a Clip value cuts at once in the browser: the first N seconds, a hard cut (no fade-in nor fade-out: Gio, same day, after trying the 1 s fade-out), 128 kbps (lamejs, 0108), uploaded as a new file with the row's progress bar (0109, phase "cutting…"). The cut starts from the file Gio dropped when it is still in memory (best quality), otherwise from the file in storage. The row's play button then plays the clip; the row name shows the length (`name.mp3 · 0:45`). Back to Full restores the file it was cut from. Nothing new in the database: the sample row keeps the key of the file in use; a replaced, saved one goes to the media trash (0009) on save. After a reload a clipped sample shows Length Full (= keep as is) with its short length.
**Rule.** A sample is trimmed in the admin, never by the player: the shop only ever holds the file it plays. Cuts start at 0:00 and end with a hard cut, no fade.
**Where.** `apps/admin/admin.js` (encodeMp3, clipSample, CLIP_DEFAULT, ListingForm: duration effect, applyClip, setLength, commitSeconds, overviewSampleItem), `apps/admin/admin.css` (`.admin-sample-clip`).
Known leak: clips cut but never saved (and a fresh upload replaced by its clip before the first save) stay in R2 unreferenced, like any upload of a form never saved.
