# 0137 — Label scanner: a small macOS app that scans straight to the 0136 file name

`2026-11-22` · accepted · Figma: BACKEND → `Scanner` (page `2423:4080`): `scan step` (state next | current | scanned; TEXT `role`, `file name`; boolean `thumbnail`), `scan preview` (state empty | preview | scanning | scanned; booleans `selection`, `caption`; TEXT `caption text`), `scanner status` (TEXT `status`, boolean `dot`); screens "Scanner - preview", "Scanner - scanning", "Scanner - label A saved"

**Context.** Gio scans labels with a Canon CanoScan LiDE 100 (works in Preview / Image Capture, so ImageCaptureCore sees it). Today he scans, then renames each file in Finder with a name copied from Edit listing → File names (0136). He wants to name the file while scanning.
**Decision (Gio 2026-11-22: "preview of the area to scan, as fast as possible… 7" preset… rotate like Preview… name before or during the scan… saves by itself in a folder I choose… choose format and resolution").**
- A native macOS app, **Zanza Scanner** (SwiftUI + ImageCaptureCore), in `apps/scanner`. One window: the record on the left (SKU, title from the slug, one `scan step` per file, then Size, Resolution, Format, Save to, scanner status); on the right the preview, the caption, then File name, **Preview** and **Scan**.
- **Preview** scans only the zone of the record, 216 × 216 mm from the corner of the glass (the whole glass for *Whole glass*), at the scanner's lowest resolution ≥ 50 dpi: as fast as the scanner goes.
- On the preview, a **square of the preset size** (7" record 180 mm, the default; Label 110 mm; Whole glass = no square) is dragged onto the record and **turned from a handle above it**, like Preview's selection. Scan reads the box around the turned square, then cuts and straightens the square in software (the scanner cannot scan a turned area).
- **File name** is a field: typed, or filled from the names pasted from the admin. It is read when the scan ends, so it can be changed while the scanner runs. The file is saved by itself as `<name>.<ext>` in **Save to** (default `~/Pictures/Zanza scans`, chosen with a folder panel and remembered); an existing file is replaced only after asking.
- **Resolution** = the scanner's own list (default 600 dpi), written in the file; **Format** = JPEG (quality 0.92), PNG or TIFF. Size, resolution, format and folder are remembered.
- **Names come from the clipboard**, not from a sign-in: Edit listing → File names gets **Copy all** (every name, one per line). When the app comes to the front with new names on the clipboard it takes them by itself (also **Paste names**, ⇧⌘V); clip names (`a1`, `b1`…) are left out. After a save the next step is selected (Label A → Label B → Other photo → `_4`, `_5`… via Add photo). The app never computes a slug: 0136's matching rule stays in the admin.
- Keys: Preview ⌘P, Scan ⌘Return.
- Built with the Command Line Tools (no Xcode on the Mac) by `apps/scanner/build.sh` into an ad-hoc-signed `.app`: runs on Gio's Mac, not notarised (no Apple Developer account).
**Update 2026-11-22 (Gio): two files per scan.** "Size" becomes **Record** (7" default, 10", 12", Whole glass). A 7" is scanned whole and every Scan writes, automatically and with the same name, **(1) the 4" label** (101.6 mm square around the spindle hole: Gio's standard label image for the shop, whatever the record size) in *Labels (4") to*, and **(2) the original** (the whole record, grooves included, 180 mm square) in *Originals to* (default `Zanza scans/Originals`). 10" and 12" do not fit the glass: the original is the 216 mm square around the label. Whole glass writes one file. The preview square is centred on the spindle hole and shows the record edge (dotted) and the 4" crop (dashed); the format picker is now "File type". Figma: `scan preview` gets `record edge` and `label crop` (boolean, on) inside `selection`; screens show Record, File type, Labels (4") to, Originals to.
**Rule.** The scanner app only uses names the admin produced or Gio typed; it never invents a slug. Visual values come from tokens.json (backend theme); native pickers and text fields are kept as macOS draws them.
**Where.** `apps/scanner/` (Sources, Info.plist, build.sh, README.md) · `apps/admin/admin.js` (fileNamesPanel → Copy all) · Figma BACKEND → `Scanner`, and `copy all` in section `file names` of "Create listing - desktop".
