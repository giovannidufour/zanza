# 0169 — Admin Dashboard: the landing page, with the shop's figures

`2026-11-24` · accepted (Gio: "fammi una dashboard dove vedo un po' di insights, ad esempio venduti, quantità di soldi incassati, valore dell'inventario online", then "fai tutto tu") · amends 0125 (nav order: Dashboard first) · Figma: BACKEND → Dashboard (component `stat` 2524:1561, frames desktop / mobile, note "dashboard behaviour"); page `admin`: `admin bar` and `admin menu` gain Dashboard (first) and Content (last, it was missing), the desktop bar wraps like the code

**Context.** Gio had no single place to see how the shop is doing: sales, money taken, what is online and what is waiting for him were spread over Listings, Orders, Offers and Memo.
**Decision.** A Dashboard page, first in the admin nav and the page the admin opens on (`#`, `#dashboard`; Listings moves to `#listings`). Read-only, computed in the browser from what the admin already reads (orders + order_items, listings, admin_offers): no migration. Two sections of `stat`s (4 columns, gap 24; one column on mobile):
- **Now**: Online now (live = available + reserved, sale and trade) · Inventory value (sum of the prices of live sale copies at a fixed price; best-offer copies have no price, so they are counted apart in the note and never added; trade has no price) · To ship (orders paid, not shipped → Orders) · Offers waiting (pending; note = accepted, not paid → Offers) · Drafts (ready / incomplete → Listings Drafts). No Memo figure: Memo is being removed from the admin (drafts replace it, Gio 2026-11-24).
- **Sales**, for the period in the tabs (This month default · This year · All time, calendar in the browser's time): Sold (sale copies with `sold_at` in the period; online = in an order, off the site = Mark as sold; traded in the note when > 0 → Listings Sold) · Money taken (record prices of paid/shipped orders, refunded/cancelled excluded, + list price of off-site sales; gross, Stripe fees are not stored; shipping charged shown apart) · Average price (money taken / priced records sold) · Days to sell (median `published_at` → `sold_at`; note = records put online in the period).
Not shown, because the data does not exist: margin (no purchase cost), Stripe fees, visits (PostHog).
**Rule.** A figure on the Dashboard says in its note how it is counted whenever a reader could count it differently (what is left out, gross or net, estimates); a missing value is never counted as zero.
**Where.** `packages/ui` (`Stat`: components.js/css/d.ts), `apps/admin/admin.js` (`Dashboard`, `dashboardFigures`, routes, `SECTIONS`, `sectionOf`; back link and Bulk create go to `#listings`), `apps/admin/admin.css` (`.admin-dashboard*`).

**Update 2026-11-24 (Gio: "se elimino un ordine, il money taken dovrebbe aggiornarsi").** Sales count only copies sold through an existing paid/shipped order (online) or marked Sold by hand in the admin (off the site: the last change to Sold in `listing_status_log` has `changed_by`; checkout writes it with no user). A copy still Sold whose order was deleted with "Keep sold" (0170) or refunded leaves Sold, Money taken, Average and Days to sell, and the Sold note says how many.
