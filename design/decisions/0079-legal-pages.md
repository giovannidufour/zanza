# 0079 — Legal pages: one text template, content in Markdown, Gio's data in site.json

`2026-11-14` · accepted (Gio: "fai tutto tu per ora, metti dei placeholder… poi fai merge"; texts by Claude, a draft, not legal advice) · Figma: page `Legal` → `legal section`, screens `Legal - desktop · Privacy`, `Legal - mobile · Privacy`

**Context.** The footer (0076) and the mobile menu (0060) link Impressum, Privacy, Terms, Withdrawal and Shipping, which returned 404. A shop selling to consumers in Germany needs them; the newsletter signup waits for a Privacy page that names Buttondown.
**Decision.** One page template for the five pages: the page title (as every page), then a `legal text` column = Divider + sections (`legal section`: heading in label/small, paragraphs and bullet lists in body/medium, text/strong). Desktop: 6 of the 12 columns (a readable line); mobile: full width. Gaps from the existing tokens: medium-small between sections, small inside one. No tab active in the header. Values still provisional are marked in the text as `[[p:value]]` (shown plain, listed by the build and in `_context/provisional-names.md` → Pagine legali). The text lives in `apps/storefront/content/legal/<page>.md` (a small closed Markdown subset, no HTML) so it can be corrected or replaced by a lawyer's text without code; `{{legal.x}}` comes from `site.json` → `legal`. An empty value shows a bracketed placeholder on the page and the build prints every placeholder left. Shipping lists the served countries by zone from the shipping config (as 0075). Pages in English, the site's and the contract's language.
Also: Inter is now served by the shop (`apps/storefront/fonts.css`), no longer by Google Fonts, so the Privacy page can say no third party is contacted for fonts (embedding Google Fonts sends the visitor's IP to Google: LG München I, 3 O 17493/20).
**Rule.** A legal or long-text page uses `legal section` / `.legal-text`, not a new layout. Personal data (name, address, email, phone, VAT) is never typed in a text file: it goes in `site.json` → `legal`. A new third-party service that sees visitors' data is added to `content/legal/privacy.md` in the same PR.
**Where.** `apps/storefront/pages/legal.js`, `legal.css`, `fonts.css`, `content/legal/*.md`, `build.js` (one page per file in `Legal.PAGES`), `site.json` → `legal`, `public/inter-*.woff2`.
