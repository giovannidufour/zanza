# 0086 — Sold-out images (rolled back: a sold copy's images look like an available one's)

`2026-11-15` · accepted (Gio: "una X bianca dello spessore di un pixel… da angolo ad angolo… applica e fai merge"; "ovviamente anche in Figma") · Figma: page `media` → `product image` (3:1006), boolean `sold out` + layer `sold out cross`

**Context.** A sold copy stays on the PLP, search, catalog and in the bag (0061, 0064), told apart only by text (struck "Sold out" button, "SOLD OUT" alert). Gio wants it visible on the image too, wherever the record is shown.
**Decision.** `product image` gets a boolean `sold out`: a vector X from corner to corner over the whole image, stroke 1px centre, `icon/strong-invert` (white), constraints scale. ON in the component, OFF in every instance (golden rule), ON where a sold copy is drawn: `bag item` status=sold, the sold cards of page `Search`. `product image` is an exposed instance in `product card` and `bag item`, so the boolean is set from the card. In code: ProductCard `soldOut`, Gallery `soldOut` (every image), BagItem status=sold (automatic). Sold out = listing status `sold` or `traded`. The storefront sets it at build time and `scripts/site.js` adds/removes it when the live status changes. Decorative (`aria-hidden`): the state is already said in text.
**Rule.** A sold copy's images always carry the cross, on every surface that shows the record; it is drawn as an SVG with `preserveAspectRatio="none"` and `vector-effect: non-scaling-stroke`, so it stays 1px corner to corner at any size. Colour only via `icon/strong-invert`.
**Where.** `packages/ui/components.js` (`SoldOutCross`, internal), `components.css` (`.zz-sold-out`), `components.d.ts`; `apps/storefront/pages/shell.js` (`isSoldOut`, ProductCardFor), `pages/pdp.js` (Gallery), `scripts/site.js` (`syncSoldCrosses`).
