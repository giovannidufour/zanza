# 0199 — Admin Edit listing: Back as a Button + Jump to (listings of the same tab)

`2026-11-27` · proposed · Figma: page `admin` → `listing nav` (2606:47524, boolean `show jump to`, on) and `jump to menu` (2606:47559, content results | no results); page `Trade` → `release option` gets `state=current`; BACKEND → Create: both Create listing frames use `listing nav` (replaces `back link`, removed), state frame "Edit listing · Jump to open" (2606:47612)

**Context.** Gio (2026-11-27): the Back link of the listing detail should follow the buttons' UI, with a leading icon; next to it a "Jump to" select that opens a menu with the listings of the same category, with image previews and a search field.
**Decision.**
- **Back** = `Button` secondary small, leading icon `icon-chevron-left-small-thin` (the library has no arrow-left; the chevron is the one the Pagination Previous uses), label = the Listings tab that holds the listing (Drafts, Live, Sold, Archived; "Listings" on Create), still a link to `#listings/<tab>` (0146). Accessible name "Back to Drafts" (contains the visible label, 2.5.3).
- **"Same category" = the same Listings tab** (0128): Live (available + reserved), Drafts, Sold (sold + traded), Archived. Sale / trade section was the other reading; the tab is what Back returns to, so the two controls share one notion.
- **Jump to** = `Button` secondary small with trailing `icon-chevron-down-large-thin` (as the Sort select), `aria-haspopup="dialog"`, `aria-expanded`. Not shown on Create listing (no tab yet).
- **Menu** = the link menu grammar (0147: 320 wide, 1px border divider/strong on surface/base, 4 under the button, search on surface/accent body/medium) over `ReleaseOption` rows: thumb 40 (the 200 px copy, as the Listings thumbnails, 0123) · title (the Listings name) · meta "SKU · price". Order = Gio's order (0129). The search matches as the Listings search (SKU, name, artists, label; case and accents ignored). The listing on screen = `current` (title underlined, as the current entity option of the link menu) and is highlighted when the menu opens. Loaded when the menu opens, so it is never stale.
- **Accessibility.** Search = combobox (`aria-controls`, `aria-activedescendant`, `aria-autocomplete="list"`) over a `listbox`; arrows / Home / End move the highlight (kept in view), Enter opens, Escape closes and returns focus to Jump to, Tab or a click outside closes. The current option carries `aria-current="page"`. Loading / no results / load error are a `role="status"` line.
**Rule.** A "go to another item of this list" control on an admin detail page is a `JumpTo` scoped to the same list the page's Back returns to; rows are `ReleaseOption` (thumb · title · meta), the item on screen is `current`.
**Open.** (1) Leaving Edit listing with unsaved changes (Back or Jump to) is not guarded, as before (design/open.md) · (2) Figma `title link menu` (Create) still shows its search at body/extra small while code uses body/medium; the new `jump to menu` follows the code.
**Where.** `packages/ui` (`ListingNav`, `JumpTo`, `ReleaseOption` `current`; `BackLink` removed), `apps/admin/admin.js` (`ListingJump`, ListingForm), `apps/admin/admin.css`.
