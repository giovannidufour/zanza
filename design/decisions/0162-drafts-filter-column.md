# 0162 — Listings → Drafts: a filter column of what a draft still needs

`2026-11-23` · accepted (Gio: "vorrei la colonna filtri nei draft in admin") · applies [0028](0028-plp-filters.md) (facet rules) and [0128](0128-listings-tabs-and-search.md) (selection reset) · Figma: BACKEND → Listings → new component `drafts filters` (2503:2114), frame "Listings - desktop · Drafts filters" (2503:2281)

**Context.** Drafts pile up from Bulk create, Memo, the Scanner and Save draft and new; the search finds one record, not "all drafts that still need a price" or "ready to publish".
**Decision.** On the Drafts tab (desktop) a 200 px column left of the bulk bar and the table, gap 24, made of the shop's `Filters` / `FilterBlock` / `Filter` (no new component in code). Blocks: Status (Ready to publish · Incomplete, the same rule as the Incomplete label and bulk Publish, `missingOf`), Missing (Artist · Format · Grading · Price), Photos (With · No photos), Samples (With · No samples), Section (Sale · Trade), Format (the admin's format list). As in the shop: OR inside a block, AND between blocks, a count is what ticking the option shows given the other blocks, an option at 0 hides unless ticked, an empty block hides. The filters work with the search (same rows in) and only on the Drafts tab; the tab counts follow the search only. The ticks stay while you switch tabs (in memory, not in the URL). Changing a filter clears the selection; while filters are on, drag ordering is off (hidden rows sit between), as with the search. The number of drafts shown is announced (role=status).
**Rule.** An admin list that needs facets reuses the shop's `Filters` / `FilterBlock` / `Filter` in a left column; its facets come from the data and follow 0028.
**Where.** `apps/admin/admin.js` (Listings: `DRAFT_FACETS`, `passes`, filter column; query adds `samples(count)`), `apps/admin/admin.css` (`.admin-listings__body`, `.admin-listings__list`).

**Update 2026-11-23 (Gio: "aggiungi anche un filtra stile text input … above the column").** A search field on top of the column (`Input variant="search"`, placeholder "Filter options", × to clear; Figma: first child of `drafts filters`, full width, gap 24 to the first block). It narrows the options, not the drafts: an option stays when every typed word is in its label or its block's name ("photos" keeps the whole Photos block), ignoring case and accents; a ticked option always stays; a block with nothing left hides. Rule: a filter column long enough to need it gets this field on top, never a second record search.

**Update 2026-11-23 (Gio: "nei filters in draft voglio anche i tag e generi").** Two more blocks after Format: Genre and Tags. Their options come from the drafts in view (the genres and Gio's tags on their releases), most used first, then A–Z; same rules as the other blocks. Figma: `drafts filters` (2503:2114) blocks `filter block · genre` and `filter block · tags`.
