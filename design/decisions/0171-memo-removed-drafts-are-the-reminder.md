# 0171 — Memo removed: a draft is the reminder

`2026-11-24` · accepted (Gio: "la sezione Memo non ha senso, perché se voglio ricordarmi di qualcosa è più semplice creare un draft") · supersedes 0087, 0135, 0140 · Figma: page BACKEND → `Memo` deleted; `admin bar` / `admin menu` without Memo; `admin page title`, `count line` (was `memo status`), `progress bar`, `photo of the label` (was `memo photo`) moved to COMPONENTS → `admin`; BACKEND → Create → `discogs actions` new variant `state=no match` (2528:40177)

**Context.** Memo (0087) was a list of records to sell later, with a photo of the label to find the release (0090), then Create draft (0135) and bulk Create drafts (0140). Since drafts can be incomplete (0107) and Create listing has the same photo of the label (0092) and Discogs search while typing (0156), a memo is just a draft with fewer fields: two places for the same thing.
**Decision.** The admin page `#memo`, its nav entry and the route `#new/memo/<id>` are removed (an old `#memo` link opens Listings). To jot a record down Gio uses **Create listing** (on the phone too): Photo of the label → pick the pressing (fetched) → **Save draft** / **Save draft and new**. Parity with Memo's free text: when the photo finds no pressing on Discogs, the words read become the title of line 1 if it is empty, so Save draft works at once (a draft needs only the line titles, 0107); the release list says so. Records still in `public.memos` are not lost: the first time Listings opens they become drafts with the same mapping as Memo's Create draft (release fetched with `packages/listing-draft`, free text = line 1), each memo deleted only after its draft is saved, one toast lists the new SKUs; a failure stays for the next visit. The table `memos` stays until Gio approves dropping it (migration). DS: `MemoItem` removed; `PhotoField`, `RecordField` (Bulk review) and `useDiscogsSearch` stay.
**Rule.** One record, one place: a reminder of a record to sell is a draft, never a second list. Before adding an admin list of "records to do something with", check whether a Listings tab or a draft field already holds it.
**Where.** `apps/admin/admin.js` (ListingForm `onPhotoFound`, `draftsFromLeftoverMemos`, PhotoField, SECTIONS), `apps/admin/admin.css` (`admin-photo`, `admin-count`, `admin-rows`), `packages/ui` (MemoItem removed).
