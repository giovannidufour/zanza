# Divider

The 1px rule between the sections of the admin form. Figma: page `divider` → `divider` (2026-11-10).

## API

No props of its own: a native `<hr>` (a thematic break for screen readers); every attribute goes to it.

## Tokens

`border-divider-strong` (as background, so the line is exactly 1px).

## Dimensions (Figma)

Height 1 · width: fills its container.
